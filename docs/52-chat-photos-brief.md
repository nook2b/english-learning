# English Club — бриф: фото для общего чата «Room 17» (юниты 005–016)

Версия 1 · 07.11.2026. Для ChatGPT (генерация картинок). В общем чате команды героини присылают фото. Сейчас вместо картинки в пузыре — текстовая заглушка. Нужно **14 фото**: предметы и места, **без людей**.

Приложено: `chat_photos_kit.zip` — фоны мест из приложения (`refs/bg_room17.png`, `bg_courtyard.png`, `bg_dining_hall.png`, `bg_shop.png`) и Рэй с рекордером (`refs/rei_with_recorder.png`), чтобы рекордер на фото был тот же.

## 1. Общие правила

- **Формат:** вертикально **1080 × 1440** (3:4), PNG. В пузыре чата фото обрезается по 3:4, на весь экран — показывается целиком.
- **Как снято на телефон героиней:** обычный ракурс с уровня глаз или чуть сверху, лёгкий наклон допустим; без «студийного» света. Рука с телефоном за кадром.
- **Стиль — как у фонов приложения** (`refs/bg_*.png`): чистый контур, плоская заливка с мягкими тенями, тёплая палитра, без зерна, без фотореализма.
- **Без людей:** ни лиц, ни рук, ни отражений в стекле и экранах.
- **Текст:** читаемы только короткие надписи из таблицы (цены, дни, время). Остальной текст — неразборчивые линии. Никаких логотипов и брендов.
- **Места — те же, что в фонах:** комната 17, двор, столовая, магазин техники. Мебель, окна и цвета стен должны совпадать с фоном этого места.
