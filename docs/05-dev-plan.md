# План разработки

> **Статус: архив версии 1.** Актуальный план разработки — [`00-full-plan.md`](00-full-plan.md), раздел 7: сначала модуль 001–004 со всеми восемью типами занятий, затем первый запуск с мини-тестом, арка 1 и проверка модели курса.

Делаем **вертикальными срезами**: после каждого этапа есть что открыть и потрогать. Арт и сюжет до готовности заменяются заглушками.

**Кто что делает**: ты пишешь сеттинг и сюжет. Код, учебный контент (по [`04-curriculum.md`](04-curriculum.md)) и вёрстку сюжета в Ink делаю я.

**Параллельность**: этапы 1–5 сюжета не требуют, их можно делать, пока ты пишешь. Этап 6 начинаем, когда готовы пролог и глава 1.

## Стек

| Задача | Технология |
|---|---|
| Приложение | React + TypeScript + Vite, PWA (vite-plugin-pwa) |
| Состояние и хранение | Zustand, Dexie (IndexedDB) |
| Повторения | ts-fsrs |
| Сюжет | Ink + inkjs |
| Telegram | Telegram Mini App SDK, бот на grammY |
| Сервер | Cloudflare Workers + D1 + Cron, хостинг Cloudflare Pages |
| Проверка контента | zod (схемы JSON) |
| Тесты | Vitest, Playwright |

## Форматы контента (примеры)

Упражнение:

```json
{
  "id": "u01-l03-e05",
  "type": "tense_choice",
  "prompt": "Look! It ___ outside.",
  "options": ["rains", "is raining"],
  "answer": "is raining",
  "explain": "Look! — действие происходит прямо сейчас → Present Continuous.",
  "tags": ["present_continuous", "contrast_ps_pc"]
}
```

Сцена в Ink с выбором-упражнением:

```ink
VAR affection_rei = 0

Rei: So you're the new member? What did you do before you came here? #rei:pout
* [I studied in Moscow.]
    ~ affection_rei += 2
    Rei: Hmph. Not bad. #rei:blush
* [I have studied in Moscow two years ago.] #mistake:pp_with_ago
    Rei: "Have studied... ago"? Seriously? #rei:smirk
* [I was study in Moscow.] #mistake:be_plus_verb
    Rei: Iris is going to cry. #rei:smirk
```

Теги `#mistake:...` связывают неверный выбор с типом ошибки: Айрис объясняет её после сцены, а предложение уходит в повторение.

## Этапы

### Этап 1. Каркас
- [ ] Vite + React + TS, линтер, тесты
- [ ] PWA: иконка, установка на телефон, офлайн
- [ ] Экраны-заглушки: Путь, Урок, Повторение, История, Профиль
- [ ] Хранилище прогресса (Dexie)
- [ ] Базовый UI-кит: кнопки, карточки, прогресс-бар, окно реплики героини
- [ ] Деплой превью на Cloudflare Pages

**Готово, когда**: открываю ссылку на телефоне и вижу главный экран.

### Этап 2. Движок упражнений + юнит 1
- [ ] Схема контента (JSON + zod)
- [ ] Типы упражнений T1, T2, T3, T4, T5, T6, T7
- [ ] Проверка ответов: сокращения, регистр, пунктуация, несколько верных вариантов
- [ ] Экран итогов урока, разбор ошибок от Айрис (спрайт-заглушка)
- [ ] Контент юнита 1 (Present Simple vs Present Continuous)

**Готово, когда**: можно пройти все уроки юнита 1.

### Этап 3. Диагностика и путь
- [ ] Диагностика: 35–45 заданий, карта времён
- [ ] Путь юнитов: блокировка, тест-аут для освоенных времён
- [ ] Контент юнитов 2 и 3

**Готово, когда**: после диагностики видно, какие времена проседают, и путь подстроился.

### Этап 4. Повторение (SRS)
- [ ] ts-fsrs, три колоды: слова, неправильные глаголы, грамматические карточки
- [ ] Автодобавление: новые слова урока и предложения с ошибками
- [ ] Ежедневная сессия повторения с лимитом новых карточек
- [ ] Работа над ошибками по тегам

**Готово, когда**: каждый день есть колода повторения, а ошибки из уроков в неё возвращаются.

### Этап 5. Геймификация
- [ ] XP, кольцо дневной цели, стрик + заморозка
- [ ] Кристаллы, магазин (заморозки, подарки героиням)
- [ ] Дневные квесты
- [ ] Недельная дуэль с Рэй (её XP подстраивается под мой темп, чтобы победа давалась с усилием)
- [ ] Экран статистики: слова, точность, ошибки по временам

**Готово, когда**: есть причина зайти завтра.

### Этап 6. Новелла и романтика
- [ ] Рендер сцены: фон, 1–2 спрайта с эмоциями, печать текста, лог, авто и пропуск
- [ ] Ink: компиляция при сборке, переменные привязанности для каждой героини
- [ ] Выборы-упражнения (теги Ink → движок упражнений, разбор ошибок)
- [ ] Перевод слова по тапу, кнопка «перевод реплики»
- [ ] Гейты: глава открывается за юнит, свидание — за юнит + привязанность
- [ ] Экран отношений, галерея CG
- [ ] Пролог и глава 1 по твоему сюжету

**Готово, когда**: после юнита 1 открывается глава 1, а мои выборы меняют привязанность.

### Этап 7. Telegram и синхронизация
- [ ] Режим Mini App: тема Telegram, кнопка «назад», вход без регистрации
- [ ] Проверка подписи данных Telegram на сервере
- [ ] Worker API + D1: синхронизация прогресса между устройствами
- [ ] Бот: ежедневное напоминание от героини с самой высокой привязанностью, предупреждение «стрик под угрозой»

**Готово, когда**: открываю приложение из Telegram на телефоне и на компьютере, прогресс один и тот же, а вечером приходит сообщение от героини.

### Этап 8. Контент и арт арки 1
- [ ] Юниты 4–7 + экзамен арки
- [ ] Главы 2–7, свидания, кульминация и признание
- [ ] Арт: 3 героини × 8 эмоций, 6–8 фонов, 5–10 CG
- [ ] Озвучка реплик (сначала браузерный TTS)

**Готово, когда**: арка 1 проходится от начала до признания.
