# English Club — план работ по полному ригу героинь

Версия 1 · 01.11.2026. План исполнения [брифа 27](27-full-rig-brief.md). Пока риг не принят, в приложении остаётся комплект v14.

## 1. Как собираем риг: варианты

| | Как | Качество | Кто что делает |
|---|---|---|---|
| **C (основной)** | Редактор Rive Early Access на Windows + официальный [Rive MCP](https://rive.app/docs/editor/ai/mcp) + локальный Claude Code | Лучшее: веса и сетки видны и правятся в редакторе, остаётся исходник `.rev`, кривые и easing — родными инструментами | Claude через MCP: слои, анимации, ключи, state machine, `CharacterVM`, data binding, эмоции, жесты. Человек: установка, держит редактор открытым, приёмка |
| C′ (если MCP не умеет кости) | То же, но каркас рига руками | То же | Человек по пошаговой инструкции: кости, привязка, сетки, веса, IK (несколько часов на героиню, разово). Остальное — Claude |
| A (запасной) | Генератор `.riv` из JSON-описания рига на сериализаторе [OpenRive](https://github.com/UpstandPlatform/OpenRive) (MIT), проверка в headless Chromium | Хуже: веса задаются числами, доводка вслепую по скриншотам; исходник — JSON, в редакторе не открыть (`.riv` в редактор не импортируется) | Всё делает Claude в облаке |

Не берём: [rivemcp](https://glama.ai/mcp/servers/paradoxsyn/rivemcp-releases/tree) — закрытый и платный, IK и веса не заявлены.

### Ограничения, которые нужно помнить

- Rive MCP слушает только `127.0.0.1:9791` на компьютере с редактором. Из облачной сессии он недоступен, а подключать папки облако умеет только с Mac или Linux. Поэтому вариант C — **локальная сессия Claude Code на Windows**.
- В документации MCP перечислены артборды, сцена, фигуры, анимации, ключи, state machine, переходы, View Model, data binding, Luau. **Кости, сетки, веса, IK, импорт картинок не названы** — проверяем первым шагом.
- Генерировать картинки Claude не умеет: слои арта (раздел 2.3 брифа) рисует ChatGPT или художник от мастера. Чистка, нарезка, проверка каймы, атлас — на Claude.

## 3. Справочные материалы

- Rive: [bones](https://rive.app/docs/editor/manipulating-shapes/bones), [meshes](https://rive.app/docs/editor/manipulating-shapes/meshes), [IK](https://rive.app/docs/editor/constraints/ik-constraint), [data binding](https://rive.app/docs/editor/data-binding/overview), [формат .riv](https://rive.app/docs/runtimes/advanced-topic/format), [MCP](https://rive.app/docs/editor/ai/mcp).
- [OpenRive: формат файла](https://github.com/UpstandPlatform/OpenRive/wiki/File-Format).
- Поворот головы 2.5D (приём из Spine, переносится на Rive): три кости — `head`, `control`, `control_back`; центр лица привязан к `control`, край — к `control_back`; при `lookX` они расходятся, дальняя половина лица сжимается. [Обсуждение на форуме Spine](https://ar.esotericsoftware.com/forum/d/29994-theres-any-more-precise-rigging-process-description-of-it).

## 4. Шаги

### Шаг 0. Разбор того, что есть (облако, параллельно с шагом 1)

1. Скачать мастер Мики (`Мика в нейтральной фронтальной позе-3.png`) и архивы ChatGPT `English_Club_FullRig_Stage0_Mika.zip`, `English_Club_Rive_v14_Part1.zip`. Если Drive-коннектор не справится с размером (38 и 32 МБ) — положить в `source/`.
2. Слои из `Stage0_Mika.zip` проверить по разделу 2.3: общий холст 2048 × 3072, дорисовано под перекрытиями, нет каймы на тёмном фоне. Составить таблицу: годится / доработать / перегенерировать от мастера.
3. Разобрать их `.riv` (парсер на основе `scripts/compress_rive.py`): кости, веса, слои state machine, интерполяции. Записать, почему анимация вышла плохо, чтобы не повторить.
4. Для недостающих слоёв — бриф на генерацию от мастера по слоям.

### Шаг 1. Проверка Rive MCP на Windows (20–30 минут)

1. Установить Rive Early Access, открыть файл с любым артбордом.
2. Установить Claude Code, открыть клон `english-learning`.
3. Подключить MCP:
   ```bash
   claude mcp add --transport http rive http://127.0.0.1:9791/mcp
   ```
4. В локальной сессии: перечислить инструменты MCP и попробовать на тестовом артборде — импорт картинки, создание кости, привязка картинки к кости, сетка, веса, IK, View Model, слой state machine.

Решение по итогам: всё есть → **C**; нет каркаса рига → **C′**; руками ригать некому → **A**.

### Шаг 2. Этап 0 брифа на Мике

Арт в позе для рига, нарезка, голова с `lookX`/`lookY` (2.5D), все эмоции, рот `mouth`, моргание, дыхание, позы `stand` и `hold_side` с `phone`, жест `wave`.

Приёмка (раздел 8 брифа): голова доходит до краёв экрана без швов и «съезжающих» черт, эмоции работают в обеих позах, на тёмном фоне чисто, не больше ~2500 вершин, 60 к/с на телефоне среднего класса при трёх героинях. **Здесь решаем, продолжаем ли в этом стиле.**

## 5. Риски

- **Качество арта для рига** — главный риск: дорисовка закрытых частей и единый стиль форм кисти. Решается брифом на послойную генерацию от мастера.
- **Возможности MCP** — могут не покрывать риг; тогда C′ или A.
- **Совместимость версий** — Early Access редактор может писать формат новее рантайма 2.44.0; проверяем на шаге 1 и при необходимости обновляем приложение (версия старше двух недель).
