# English Club — план работ по полному ригу героинь

Версия 2 · 01.11.2026. План исполнения [брифа 27](27-full-rig-brief.md). **Выбран вариант C**: редактор Rive + Rive MCP + локальный Claude Code. Пока риг не принят, в приложении остаётся комплект v14.

## 1. Вариант C: кто что делает

| | Кто | Что |
|---|---|---|
| Редактор | Rive Early Access, десктоп (Windows; macOS тоже поддерживается) | Исходник рига, веса и сетки правятся вживую, экспорт `.riv` и бэкап `.rev` |
| Claude, локально | Claude Code на том же компьютере, подключён к [Rive MCP](https://rive.app/docs/editor/ai/mcp) | Артборд, иерархия, анимации и ключи, state machine, `CharacterVM`, data binding, эмоции, жесты |
| Человек | | Установка, держит редактор открытым, **каркас рига руками** (кости, привязка, сетки, веса, IK) по пошаговой инструкции от Claude — пока MCP этого не умеет, приёмка |
| Claude, облако | эта сессия | Арт: проверка, чистка, обрезка слоёв, сборка PSD для импорта; подключение в приложение, сжатие, проверка на рантайме |

Запасной путь — генератор `.riv` из JSON на [OpenRive](https://github.com/UpstandPlatform/OpenRive) (бывший вариант A) — не планируем; возвращаемся к нему, только если вариант C встанет целиком.

### Ограничения, которые нужно помнить

- **MCP слушает `http://127.0.0.1:9791/mcp`** и работает, только пока открыт десктопный Rive Early Access (Windows или macOS, в браузерном редакторе MCP нет). Из облачной сессии он недоступен: подключать компьютер облако умеет только с Mac или Linux, и даже тогда команды идут на компьютере, а не в облаке. Поэтому работа с редактором — **локальная сессия Claude Code**.
- **MCP не умеет кости, сетки, веса, IK и импорт картинок**: в [списке возможностей](https://rive.app/docs/editor/ai/mcp) их нет (есть только «asset-based elements», список обещают расширять). Значит, каркас рига по умолчанию делает человек; шаг 1 проверяет, не появилось ли это в текущей сборке.
- **Нужен платный план Rive, минимум Cadet ($9/мес)**. На бесплатном плане `.riv` экспортируется **с заставкой Rive**, которая проигрывается в приложении; бэкап `.rev` — только на платных планах; импорт ограничен 10 МБ на файл (на Cadet — 100 МБ).
- **`.riv` в редактор не импортируется** — исходник рига только `.rev` (или файл в облаке Rive). Ригать готовые `.riv` от ChatGPT нельзя, их можно только разобрать.
- **Атлас текстур возможен через сетки**: сетка картинки берёт свой участок общей текстуры. Так собрана проба ChatGPT: один атлас 2048 × 2048 на 29 сеток ([разбор](29-rig-step0.md)). Слои всё равно обрезаются по содержимому (шаг 2.2).
- **Совместимость рантайма**: формат файла сейчас 7, его читают и редактор Early Access, и наш `@rive-app/canvas@2.44.0`. Опасность не в формате, а в **новых возможностях**: то, чего старый рантайм не знает, он молча пропускает. Поэтому каждый экспорт проверяется на нашей версии рантайма, а не только в редакторе.
- **Без скриптов Luau** (бриф 27, раздел 7): MCP их умеет, но не используем, если не согласовано.
- Генерировать картинки Claude не умеет: слои арта (раздел 2.3 брифа) рисует ChatGPT или художник от мастера. Проверка, чистка, обрезка и сборка — на Claude.

- Поворот головы 2.5D (приём из Spine, переносится на Rive): три кости — `head`, `control`, `control_back`; центр лица привязан к `control`, край — к `control_back`; при `lookX` они расходятся, дальняя половина лица сжимается. [Обсуждение на форуме Spine](https://ar.esotericsoftware.com/forum/d/29994-theres-any-more-precise-rigging-process-description-of-it).

### Шаг 1. Установка и проверка MCP (компьютер, 30–40 минут)

1. Оформить план Rive Cadet (или выше). Установить Rive Early Access, открыть новый файл.
2. Установить Git for Windows и Claude Code, клонировать `english-learning`, открыть его в Claude Code.
3. Подключить MCP (редактор должен быть открыт):
   ```bash
   claude mcp add --transport http rive http://127.0.0.1:9791/mcp
   ```
4. В локальной сессии: перечислить инструменты MCP и попробовать на тестовом артборде — импорт картинки, кость, привязку картинки к кости, сетку, веса, IK, View Model с Enum, слой state machine, экспорт.
5. Экспортировать тестовый `.riv`, прогнать на рантайме `2.44.0` (без заставки, data binding работает).
6. Проверить, открывается ли в редакторе `scene.rml` из пробы ChatGPT (импортом или через Rive CLI 1.8.0). Если да, Мика стартует с готового каркаса пробы: 21 кость, IK, сетки и state machine уже есть ([шаг 0](29-rig-step0.md), раздел 4).

Итог шага — список: что делает Claude через MCP, что делает человек руками. Ожидаемо руками: импорт слоёв, кости, привязка, сетки, веса, IK.

### Шаг 2. Этап 0 брифа на Мике

1. **Арт** (облако): позы для рига по 2.2, слои по 2.3.
2. **Подготовка к импорту** (облако): каждый слой обрезать по содержимому с запасом в несколько пикселей и собрать **многослойный PSD** с исходными координатами — Rive импортирует PSD со слоями на своих местах. Полноэкранные PNG 2048 × 3072 не импортируем: при ~80 слоях это ~2 ГБ видеопамяти в рантайме вместо нескольких десятков МБ.
3. **Каркас** (человек по инструкции Claude): импорт PSD, кости (таз → позвоночник ×2 → шея → голова; руки; ноги; `control`/`control_back` для головы; цепочки волос), привязка, сетки, веса, IK рук. Сохранить `.rev`.
4. **Анимация и логика** (Claude через MCP): `CharacterVM` v2 по разделу 4 брифа, слои state machine по разделу 3, эмоции, рот `mouth`, моргание, дыхание, `lookX`/`lookY`, позы `stand` и `hold_side` с `phone`, жест `wave`.
5. **Подключение в приложение** (облако): сейчас `RiveHeroine.tsx` выбирает артборд по позе (`artboard: pose`) и пересоздаёт героиню при её смене. В риге один артборд `Character`, поза — свойство `pose`: загружать `Character`, менять `pose` через View Model без перезагрузки; v14 остаётся запасным, пока риг не принят.

Приёмка (раздел 8 брифа):
- при `lookX`/`lookY` от −1 до 1 голова и взгляд **поворачиваются к краям экрана** без швов и «съезжающих» черт, похоже на кадры ¾ из 2.2;
- любая эмоция работает в обеих позах;
- на тёмном фоне чисто, без каймы;
- не больше ~2500 вершин; 60 к/с на телефоне среднего класса при **трёх копиях Мики** на экране (других героинь ещё нет);
- позы, жесты и повороты на кубических кривых, не линейных;
- лицо похоже на мастер: черты лица растровые, от мастера, в настоящем 2×;
- работает на `@rive-app/canvas@2.44.0`, без заставки.

## 5. Риски

- **Качество арта для рига** — главный риск: дорисовка закрытых частей и единый стиль форм кисти. Решается брифом на послойную генерацию от мастера.
- **Ручной каркас** — несколько часов на героиню; без человека, готового это сделать, вариант C не идёт. Снижается пошаговой инструкцией и тем, что одинаковый скелет переносится между героинями.
- **Новые возможности редактора**, которых нет в рантайме 2.44.0, молча не работают. Ловим проверкой каждого экспорта на нашем рантайме; при необходимости обновляем приложение (версия старше двух недель).
- **Видеопамять на телефоне** при трёх героинях — держим слои обрезанными и замеряем на этапе 0.
