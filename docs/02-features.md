# Каталог функционала

Всё, что встречается в приложениях для изучения языков, плюс функции под аниме-героинь. У каждой функции есть ID, чтобы выбирать по номерам («берём B7, C3, убираем E7»).

**Сложность**: S — дни, M — 1–2 недели, L — 3–6 недель, XL — больше (для небольшой команды).
**Рекомендация**: ⭐ MVP, 🔜 v1.x (сразу после запуска), 🕐 v2 (позже), ⛔ не советую.

> **Принятые решения (29.10.2026)**: проект **личный**, платформа **веб + Telegram → потом мобильное**, ядро MVP — **уроки по CEFR + SRS** и **визуальная новелла**, героини с **романтической линией**.
> Итоговый состав MVP и романтические механики R1–R7 описаны в [`03-plan.md`](03-plan.md), раздел 4.
> Для личного проекта не нужны блоки **F** (социальные функции) и **G** (монетизация), а также E7 (лиги заменены дуэлью с героиней), A5 (вход через Telegram), H3–H5 (локализация, аналитика, админка). Ниже каталог оставлен целиком как справочник.

## Моя рекомендация для MVP

**Ядро обучения**: A1–A5, B1, B2, B3, B5, B6, B7, C1, C2, C3
**Героини**: D1 (3 героини), D2, D3, D4, D5, D6
**Геймификация**: E1, E2, E3, E4, E5
**Бизнес и сервис**: G1, H1–H5

Итого около 30 функций. Логика такая: MVP должен проверить одну гипотезу: **«героини + сюжет + AI-общение удерживают лучше обычного Duolingo-клона»**. Лиги, друзья и голосовые звонки добавляем, когда гипотеза подтвердится и появится база пользователей.
