# English Club — бриф: героини в Rive с эмоциями и липсинком

**Выполнено 30.10.2026 (версия 4 комплекта):** `assets/rive/{mika,rei,iris}.riv` с позами и эмоциями по разделу 3 подключены в сценах, заданиях и на страницах героинь. Списки эмоций — `assets/rive/expressions.json` (из `contract.json`). Рот — громкость голоса 0…1 в `mouth`, `talking` на время реплики. Эмоция, которой нет в позе (например, `sad`), показывается спрайтом. Заглушки PNG не понадобились: под анимацией лежит спрайт той же позы и эмоции, кадры совпадают до пикселя. `nod` и `viseme` не сделаны (необязательны).

**Сжатие (31.10.2026).** Текстуры в `.riv` комплекта — PNG без потерь, это 90–97% размера. `scripts/compress_rive.py` перекодирует их в WebP качества 90 прямо внутри файла (у каждой текстуры свой префикс длины, абсолютных смещений нет): 10,2 МБ → 2,4 МБ на троих. Проверено сравнением рендера в браузере, 9 поз × все эмоции × 3 положения рта: средняя разница 2 из 255, не больше 6 заметно отличающихся пикселей на кадр. 256 цветов, как у TinyPNG, дают полосы на волосах — не подходит. Каждый новый комплект прогонять через скрипт:

```sh
python3 scripts/compress_rive.py rive/mika.riv assets/rive/mika.riv
```

Версия 1 · 30.10.2026. Что точно нужно, чтобы Rive-героини заменили спрайты в диалогах и говорили с движением губ. Первая версия (MVP: дыхание, покачивание, моргание) уже стоит на страницах героинь.

## 1. Зачем

Сейчас в сценах героиня — набор PNG: поза × эмоция и патч рта для речи. Rive-версия должна уметь всё то же самое и вдобавок жить: дышать, моргать, плавно менять эмоции и двигать губами под голос.

Приложение управляет героиней **только через View Model**: выбирает эмоцию, открывает рот по громкости голоса, включает и выключает движение. Поэтому главное в брифе — **точные имена** артбордов, свойств и значений. Если имя отличается хоть на букву, приложение его не найдёт.

## 2. Контракт с приложением (обязательно)

### Файлы

| Файл | Что внутри |
|---|---|
| `rive/mika.riv` | Мика: артборды `stand` и `phone` |
| `rive/rei.riv` | Рэй: артборды `stand` и `recorder` |
| `rive/iris.riv` | Айрис: артборды `stand` и `notebook` |
| `rive/{героиня}_{поза}.png` | Неподвижный кадр каждой позы с нейтральным лицом (показывается, пока грузится анимация) |
| исходники `scene.rml` и ассеты | Чтобы файл можно было пересобрать и править |

Имена героинь — `mika`, `rei`, `iris` (не `blonde` / `goth` / `scholar`, как в MVP).

### Артборд

- **Один артборд на позу**, имя артборда = имя позы: `stand`, `phone`, `recorder`, `notebook`.
- Размер **1024 × 1536**, героиня целиком, макушка ~60 px от верха, подошвы ~40 px от низа — **как у наших спрайтов**, чтобы при смене спрайт ↔ Rive ничего не прыгало.
- Поза и наряд — **как у спрайта этой позы** (`assets/characters/{героиня}/base/{поза}/`). Наряд пока только `base`.
- State Machine на каждом артборде: `CharacterSM`.

### View Model `CharacterVM` (на каждом артборде одинаковая)

| Свойство | Тип | Значения | Что делает |
|---|---|---|---|
| `motionEnabled` | Boolean | по умолчанию `true` | Дыхание, покачивание, моргание. `false` — стоит неподвижно (для «уменьшения движения» в настройках телефона) |
| `expression` | Enum `Expression` | имена эмоций позы, раздел 3 | Какое лицо сейчас. Смена — плавная, 100–150 мс |
| `mouth` | Number | от `0` до `1` | Насколько открыт рот: `0` — закрыт, `1` — открыт полностью. Приложение меняет его каждый кадр по громкости голоса |
| `talking` | Boolean | по умолчанию `false` | Героиня говорит: лёгкие кивки головой в такт фразе. Без него рот всё равно открывается по `mouth` |

Необязательно, но полезно (если делается легко):

| Свойство | Тип | Что делает |
|---|---|---|
| `nod` | Trigger | Один короткий кивок (героиня реагирует на верный ответ) |
| `viseme` | Enum `Viseme`: `rest`, `a`, `e`, `o`, `mbp`, `fv` | Форма рта под звук речи — на будущее, для точного липсинка. Если есть, `mouth` задаёт раскрытие, а `viseme` — форму |

Значения по умолчанию в инстансе: `motionEnabled = true`, `expression` = нейтральная эмоция позы (`neutral`, у `phone` Мики и `notebook` Айрис — `focused`), `mouth = 0`, `talking = false`.

## 4. Как собрать персонажа

Риг MVP — одна сплошная сетка с накладкой век. Для эмоций и речи нужны **отдельные слои**:

1. **Тело** — сетка, как в MVP: дыхание, покачивание.
2. **Голова** — отдельный узел поверх тела, небольшой наклон и кивок (для `talking` и `nod`). Шея должна прятать стык.
3. **Лицо по эмоциям** — для каждой эмоции свой кадр лица (глаза, брови, щёки). Переключаются по `expression`.
4. **Веки** — моргание поверх любого лица, как в MVP.
5. **Рот по эмоциям** — для каждой эмоции **три кадра рта**:
   - `closed` — рот закрыт (это и есть рот эмоции: по правилу брифа 17 у спрайтов рот закрыт);
   - `half` — приоткрыт;
   - `open` — открыт, как в кадре речи.

   Переключение по `mouth`: до `0.2` — `closed`, от `0.2` до `0.55` — `half`, выше — `open`. Форма и ширина улыбки у всех трёх кадров одной эмоции одинаковые: двигается только нижняя губа и челюсть.

**Откуда взять картинки — они почти все уже есть:**
- база позы — `assets/characters/{героиня}/base/{поза}/{база}.webp` (у `stand` — `neutral`, у остальных — `focused`);
- лица эмоций — те же файлы эмоций: они отличаются от базы **только в области лица** (так их делали по брифам 11 и 17);
- открытый рот — патчи `{эмоция}_talk@x,y,w,h.webp`: это вырезанные участки рта, координаты в имени файла;
- `half` нужно дорисовать: та же правка рта, что для кадра речи, но рот открыт наполовину.

Лучше брать **оригинальные PNG**, а не WebP из репозитория: так меньше потерь качества. Если оригиналов нет, подойдут и WebP; патчи рта хранятся без потерь.

## 5. Ограничения

- **Размер:** до ~3 МБ на героиню (весь `.riv` со всеми позами). Лица и рты — небольшими вырезками, а не полными кадрами 1024 × 1536.
- **Стиль** — как у спрайтов: чистые контуры, плоская заливка, без зерна и шума. Сетка не должна «плыть» на лице: лицо не деформировать, только подменять кадры.
- **Рантайм:** приложение использует `@rive-app/react-canvas` (Canvas 2D). Не использовать Vector Feathering и скрипты Luau: в Canvas 2D их нет.
- Без звука внутри `.riv`: голос играет приложение.

## 6. Проверка перед отправкой

- [ ] Имена совпадают с разделом 2: файлы, артборды, `CharacterSM`, `CharacterVM`, свойства и типы.
- [ ] Enum `Expression` на каждом артборде — ровно список из раздела 3.
- [ ] `mouth` = 0 → рот закрыт; 0.4 → приоткрыт; 1 → открыт; у каждой эмоции.
- [ ] Смена `expression` плавная, без прыжка головы и тела.
- [ ] `motionEnabled = false` — неподвижно, лицо и рот всё равно переключаются.
- [ ] Моргание работает поверх любой эмоции.
- [ ] Холст и положение героини совпадают со спрайтом той же позы (наложить PNG спрайта поверх кадра Rive — контуры тела совпадают).
- [ ] Размер файла каждой героини — до ~3 МБ.

## 7. Что сделаю в приложении

Когда пришлёшь файлы:
1. **Диалоги и сцены:** героиня в позе сцены (`stand`, `phone`…) ставится Rive-артбордом, эмоция реплики идёт в `expression`. Если для какой-то позы или наряда Rive нет, остаётся спрайт.
2. **Липсинк:** громкость голоса я уже меряю для нынешней анимации рта. Каждый кадр она будет уходить в `mouth` (со сглаживанием), а на время реплики — `talking = true`. Работает со всей уже записанной озвучкой, перегенерировать ничего не нужно.
3. **Точный липсинк (позже, если будет `viseme`):** перегенерировать озвучку ElevenLabs с таймингами букв и по ним выставлять форму рта. Это заново тратит символы ElevenLabs, поэтому только по решению.
4. Страницы героинь, карта и «После уроков» переходят на Rive там, где совпадают позы.
