# English Club — Live2D Cubism: разбор и бриф на пробу (пролог)

Версия 1 · 01.11.2026. Отвечает на вопрос «сделать ли анимацию героинь на Live2D Cubism вместо Rive». Короткий ответ: **да, для полного рига ([бриф 27](27-full-rig-brief.md)) Live2D подходит лучше Rive**, но проверяем это пробой на одной героине в одной сцене — прологе. Комплект Rive v14 остаётся в приложении, пока проба не принята.

## 1. Что такое Live2D Cubism

Live2D Cubism — японский стандарт «живых» 2D-персонажей: визуальные новеллы и гача-игры (героини в диалогах), VTuber-аватары. Рисунок режется на слои, каждый слой становится сеткой (ArtMesh), сетки сидят в деформерах, а деформеры двигаются **параметрами** (`ParamAngleX`, `ParamEyeLOpen`, `ParamMouthOpenY`…). Риггер для каждого параметра задаёт крайние положения (ключевые формы), программа плавно смешивает их между собой. Так получается главный эффект Live2D — **поворот головы «почти в 3D»** из плоского рисунка.

Из чего состоит экосистема:

| Часть | Что это | Для нас |
|---|---|---|
| **Cubism Editor** (Windows, macOS) | Программа риггера: импорт PSD, сетки, деформеры, параметры, физика, анимации | Работает художник-риггер, не я |
| **Cubism Viewer** | Бесплатный просмотрщик готовой модели | Ты смотришь, что сдали |
| **Cubism SDK for Web** | TypeScript-фреймворк (открыт, GitHub) + **Cubism Core** (закрытая библиотека, скачивается с сайта Live2D) | Подключаю я, в приложение на React |
| **MotionSync Plugin for Web** | Липсинк по звуку: рот складывается по гласным, без лицензионных отчислений | Подключаю я, к нашим клипам ElevenLabs |

Файлы, которые выдаёт Editor для приложения: `*.model3.json` (оглавление), `*.moc3` (сама модель), текстуры PNG, `*.physics3.json` (физика волос и одежды), `*.exp3.json` (эмоции), `*.motion3.json` (анимации), `*.pose3.json` (переключение частей, например рук), `*.cdi3.json` (имена параметров).

## 2. Почему для нас Live2D лучше Rive

Бриф 27 по сути описывает именно то, ради чего сделан Live2D. В Rive многое из него придётся изобретать вручную:

| Что нужно по брифу 27 | Rive | Live2D |
|---|---|---|
| Поворот головы ¾ без «съезжающих» черт (`lookX`, `lookY`) | Собирать вручную костями и сетками; самая рискованная часть брифа | Основная функция: параметры `ParamAngleX/Y/Z`, ключевые формы, инструменты автоматического поворота |
| Волосы, хвост Мики, серьги, цепочки Рэй с запаздыванием | Нет физического движка, имитация ограничениями | **Встроенная физика** (маятники), работает и в веб-рантайме |
| Любая эмоция в любой позе | Слои state machine | Эмоции — наборы параметров (`exp3.json`), смешиваются с любой позой сами |
| Липсинк | 3 кадра громкости, виземы — задача на будущее | Параметры рта + плагин MotionSync; или я веду рот сам по таймингам ElevenLabs |
| Моргание, дыхание, взгляд за собеседником | Анимации в файле | Стандартные параметры, SDK делает моргание и дыхание сам |
| Специалисты | Мало аниматоров персонажей именно в Rive | **Тысячи риггеров** (рынок VTuber), понятные цены и портфолио |

Чего у Live2D нет и что это значит:

- **Нет state machine и View Model**, как в Rive. Логику (когда кивнуть, куда смотреть, какую эмоцию включить) пишу я в коде. Это даже удобнее: контракт брифа 27 (раздел 4) остаётся тем же, только он будет в коде приложения, а не в файле.
- **Тяжелее рантайм**: WebGL плюс отдельная библиотека Cubism Core вместо Rive wasm. Три героини на одном холсте на среднем телефоне — обычный для Live2D сценарий, но я проверю это на пробе.
- **Cubism Core — закрытая библиотека**: её нельзя поставить из npm, файл кладу в проект сам по лицензии Live2D.
- **Плоский вектор и мелкие UI-анимации** (иконки, кнопки) остаются в Rive или CSS — Live2D только для героинь.

## 3. Могу ли я работать с Live2D через API

Честно по частям:

| Задача | Могу? | Как |
|---|---|---|
| Подключить модели в приложение, управлять ими из кода | **Да, полностью** | SDK for Web; компонент `Live2DHeroine` вместо `RiveHeroine` с теми же входами: эмоция, речь, наклон, значки, реакции |
| Писать анимации и эмоции (`motion3.json`, `exp3.json`) | **Да** | Это JSON с кривыми параметров. Кивки, реакции (`nod`, `hop`, `laughShake`, `sigh`), жесты, «живая голова при речи» я могу делать сам, без риггера, когда параметры уже есть в модели |
| Липсинк по голосу | **Да** | ElevenLabs отдаёт тайминги символов → я перевожу их в параметры рта по времени; запасной вариант — громкость, как сейчас |
| Взгляд и поворот к говорящей | **Да** | Задаю `ParamAngleX`, `ParamEyeBallX`, `ParamBodyAngleX` по правилам брифа 27, раздел 5.4 |
| Страница проверки модели с ползунками | **Да** | Сделаю отдельный экран для разработчика в приложении: все параметры, эмоции, анимации, тёмный фон |
| Нарезать арт на слои и сделать риг (сетки, деформеры, ключевые формы) | **Нет** | Это ручная работа в Cubism Editor на Windows или macOS. Мой контейнер — Linux в облаке, Editor здесь не запускается |
| Управлять Editor через его API | **Частично, и только на твоём компьютере** | У Editor есть официальный «External Application Integration API» (WebSocket, порт 22033): **читать и ставить значения параметров, читать структуру, узнавать об экспорте**. Создавать или править риг он не умеет. Есть неофициальный MCP-сервер `cubism-mcp`, который умеет больше (добавлять параметры, деформеры, ключи), но он работает только с альфа-версией Editor 5.4, срок которой, по его README, истёк 14.09.2026. Для нашей работы не нужен |

**Skills и плагины**: проверил каталог skills и плагинов Claude — для Live2D ничего нет. Готового «скилла» нет; если проба пойдёт, я оформлю нашу схему (имена параметров, правила анимаций, проверки) как правило в репозитории, как сейчас бриф и `23-story-rules.md`.

## 4. Лицензия и деньги

- **Cubism SDK** (то, что в приложении): для физлиц и небольших компаний с годовой выручкой **до 10 млн иен** (~ 65 тыс. $) — бесплатно. Наше личное приложение подходит. Если появится выручка выше порога — нужна платная лицензия на выпуск (SDK Release License), её цена зависит от платформ (Web, iOS, Android считаются отдельно).
- **Cubism Editor**: есть FREE-версия, но с лимитами (100 сеток, 30 параметров, 50 деформеров, 1 текстура до 2048 px) — нашей модели этого не хватит. Риггер работает в PRO (у профессионала она обычно уже есть). PRO — подписка, есть пробный период 42 дня; актуальная цена — в магазине Live2D.
- **Художник и риггер** — основная статья расходов. Цены на рынке очень разные; запроси 2–3 предложения по разделу 7 этого брифа.

## 5. Решение

1. **Проба Live2D на Мике в прологе** (этап 0 ниже). Мика — центр кадра, больше всего реплик и эмоций.
2. Если проба лучше Rive v14 и проходит по скорости на телефоне — делаем на Live2D весь бриф 27 (Рэй и Айрис, затем руки, предметы, жесты). Арт по брифу 27, раздел 2, переиспользуется: нужно лишь собрать его в PSD по правилам Live2D (раздел 7).
3. Если нет — продолжаем бриф 27 в Rive, потеряв только стоимость пробы.

# Бриф на пробу: Мика, пролог «Не тот кабинет»

## 6. Сцена, ради которой делаем пробу

Пролог: комната 17, старый корпус. Слева Рэй с рекордером, в центре **Мика**, справа Айрис. Игрок зашёл не в тот кабинет. Реплики Мики (из `content/story/prologue.json`):

| # | Реплика | Эмоция | Что должна сделать Мика |
|---|---|---|---|
| 1 | — (говорит Рэй: «The cable. Careful.») | `listening` | Смотрит на Рэй (влево), затем вниз на кабель |
| 2 | Are you here for the guide? Great! We need someone who is new here. | `excited` | Подаётся вперёд, глаза шире, голова к игроку, хвост качнулся |
| 3 | — (говорит Айрис: «One question first…», «Seventy…») | `listening` | Поворачивает голову к Айрис (вправо), корпус наполовину |
| 4 | I'm Mika. This is Rei, and this is Iris. What's your name? | `happy` | Взгляд на игрока → на Рэй → на Айрис → снова на игрока (жест представления рукой — этап 2, в пробе только взгляд и голова) |
| 5 | Nice to meet you! You have time. The New Building is five minutes away. | `happy` | Тёплая улыбка, лёгкий кивок |
| 6 | We're making an audio guide for new students. Come back after your check if you have time. | `happy` | Живая голова при речи, в конце маленький наклон головы |
| 7 | — (Рэй: «And the door will still say seventeen.») | `laugh` | Смеётся над шуткой Рэй: плечи и хвост вздрагивают |

Остальные эмоции из её словаря (раздел 8.3) нужны в пробе тоже: проверим, что они работают на одном теле.

## 7. Что подготовить художнику (арт)

### 7.1. Источник и стиль

- Только от мастера `source/masters/mika.png` (правило `MASTER_REFERENCES.md`), без цепочек перегенераций.
- Стиль как сейчас: чистый тёмный контур, плоская заливка, мягкие тени, **без зерна, шума и текстур**.
- Поза — как в брифе 27, раздел 2.2: стоит прямо, анфас, руки опущены и чуть отведены от тела, рот закрыт, взгляд прямо, наряд `base`.
- Плюс образцы для риггера (не для склейки): голова в ¾ влево и вправо, голова чуть вверх и вниз.

### 7.2. Формат файла — один PSD

- **PSD**, RGB 8 бит, профиль sRGB, холст **3000 × 4500 px** (больше брифа 27: Live2D любит запас, текстуры потом всё равно ужмёт до атласа).
- Каждая деталь — отдельный растровый слой; **не** смарт-объекты, **не** корректирующие слои, **не** режимы наложения кроме «Обычный» и «Умножение» для теней (лучше всё слить в обычные слои). Маски слоёв применить.
- Слои сгруппированы по частям и названы по-английски, как в таблице 7.3.
- **Всё скрытое дорисовано**: шея под волосами, лоб под чёлкой, бока под руками, задняя часть волос за головой, внутренняя часть рта, белок под веками. При повороте головы открывается до 15–20% «невидимого», поэтому лицо и волосы сзади рисуются с запасом.
- Без светлой каймы по краям слоёв, проверять на тёмном фоне.

### 7.3. Слои (Live2D-нарезка)

| Группа | Слои |
|---|---|
| `Eyes_L`, `Eyes_R` | `eye_white`, `iris`, `pupil`, `highlight`, `lid_upper` (линия века с ресницами), `lid_lower`, `lashes`, `eye_closed_line` (линия закрытого глаза — для моргания и смеха) |
| `Brows` | `brow_l`, `brow_r` |
| `Mouth` | `lip_upper` (линия), `lip_lower`, `mouth_inner` (тёмная полость), `teeth_upper`, `teeth_lower`, `tongue`. **Один рот, который деформируется**, а не набор нарисованных ртов |
| `Face` | `face` (кожа без черт), `nose`, `blush`, `face_shadow` (тень от чёлки), `ear_l`, `ear_r` |
| `Hair_Front` | `bangs_1…3` (чёлка прядями), `side_lock_l`, `side_lock_r` |
| `Hair_Back` | `hair_back`, `ponytail_1…4` (хвост цепочкой для физики), `scrunchie` |
| `Body` | `neck`, `neck_shadow`, `torso`, `chest`, `top`, `skirt`, `skirt_bow`, `bag`, `bag_strap` |

## 8. Что подготовить риггеру (Cubism Editor 5, PRO)

### 8.1. Параметры — точные ID

Стандартные ID Live2D, чтобы работали автоматика SDK и мои анимации:

| ID | Диапазон | Что |
|---|---|---|
| `ParamAngleX` | −30…30 | поворот головы влево-вправо (**главное в пробе**) |
| `ParamAngleY` | −30…30 | вверх-вниз |
| `ParamAngleZ` | −30…30 | наклон головы |
| `ParamBodyAngleX`, `ParamBodyAngleY`, `ParamBodyAngleZ` | −10…10 | корпус: доворот к собеседнице, наклон вперёд (`excited`) |
| `ParamBreath` | 0…1 | дыхание |
| `ParamEyeLOpen`, `ParamEyeROpen` | 0…1 (до 1.2 — широко открыты) | моргание, удивление |
| `ParamEyeLSmile`, `ParamEyeRSmile` | 0…1 | глаза-«улыбка» (`happy`, `laugh`) |
| `ParamEyeBallX`, `ParamEyeBallY` | −1…1 | взгляд |
| `ParamBrowLY`, `ParamBrowRY`, `ParamBrowLForm`, `ParamBrowRForm`, `ParamBrowLAngle`, `ParamBrowRAngle` | −1…1 | брови |
| `ParamMouthOpenY` | 0…1 | раскрытие рта |
| `ParamMouthForm` | −1…1 | уголки рта: грусть ↔ улыбка |
| `ParamA`, `ParamI`, `ParamU`, `ParamE`, `ParamO` | 0…1 | формы рта под гласные (для липсинка) |
| `ParamCheek` | 0…1 | румянец |
| `ParamHairFront`, `ParamHairSide`, `ParamHairBack`, `ParamPonytail` | −1…1 | движение волос (ведёт физика) |
| `ParamSkirt`, `ParamBagSway` | −1…1 | юбка, сумка (физика) |
| `ParamShoulderY` | −1…1 | плечи вверх (смех, вздох) |
| `ParamArmLA`, `ParamArmRA` | −10…10 | руки чуть в стороны и обратно (для живости; полные руки — этап 2) |

Свои параметры — только с префиксом `ParamMika…` и списком в `CHANGELOG.md`.

### 8.2. Обязательное качество

- **Поворот головы**: при `ParamAngleX = ±30` черты сдвигаются в сторону поворота, дальняя щека сжимается, хвост и задние волосы уходят в противоположную сторону, чёлка — с параллаксом. Ориентир — образцы ¾ из 7.1. Комбинации X и Y (углы 3×3) без изломов.
- **Физика** (`physics3.json`): хвост из 4 звеньев с запаздыванием, чёлка, боковые пряди, юбка и сумка от `ParamAngleX`, `ParamBodyAngleX` и `ParamBodyAngleZ`. Хвост не должен проходить сквозь тело.
- Без швов на шее при любых сочетаниях параметров.
- Рот в любой эмоции открывается по `ParamMouthOpenY` и складывается по `ParamA…ParamO` без разрывов контура.

### 8.3. Эмоции (`exp3.json`, по файлу на эмоцию)

Все работают в любой позе: `neutral`, `listening`, `happy`, `laugh`, `excited`, `surprised`, `thinking`, `focused`, `embarrassed`, `annoyed`, `pout`, `forced_smile`, `sad`, `worried`. Имена файлов — ровно эти: `happy.exp3.json`. Эмоция задаёт брови, глаза, форму рта и румянец, **не трогает** углы головы и рот-раскрытие: ими управляю я.

### 8.4. Анимации (`motion3.json`)

От риггера в пробе — только:

- `idle.motion3.json` — зацикленное дыхание и микродвижения корпуса, 4–6 с;
- `laugh.motion3.json` — вздрагивание плечами и хвостом, 1 с;
- `excited.motion3.json` — подача вперёд и возврат, 0,8 с.

Кивки, «живую голову при речи», повороты к собеседнице и остальные реакции (`nod`, `hop`, `sigh`, `headShake`) сделаю я сам по параметрам 8.1 — пусть риггер сделает их пример, если успеет, для сравнения.

### 8.5. Технические рамки

- Текстуры: **один атлас 2048 × 2048** (если не помещается — два). На сцене три героини, у каждой своя модель.
- Ориентир — не больше ~3000 вершин на модель; маски (clipping) — только где без них нельзя (глаза, рот).
- Экспорт под **Cubism SDK 5** (moc3 последней версии, которую поддерживает текущий SDK for Web); ничего из функций, которые SDK for Web не поддерживает (смотри «SDK compatibility» для 5.3).
- Кадрирование: в сцене от макушки до колен, на странице героини — целиком. Рост и линия пола — как у текущей Мики (под них откалиброваны фоны, [бриф 25](25-backgrounds-brief.md)).

### 8.6. Что сдать

- `mika.model3.json`, `mika.moc3`, текстуры, `mika.physics3.json`, `mika.cdi3.json`, эмоции 8.3, анимации 8.4;
- исходники: `mika.cmo3`, `mika.can3`, PSD;
- `CHANGELOG.md` со списком параметров и их значений по умолчанию;
- короткое видео: поворот головы по кругу, все эмоции подряд, реплики 2 и 7 из таблицы 6.

2. **Исполнитель**: найти риггера Live2D (часто это и художник, который режет PSD, — удобнее одному человеку). Показать ему разделы 6–8 и портфолио с **поворотом головы ±30°** и физикой волос — это главное.
3. **Арт**: если художник отдельно — PSD по разделу 7 от мастера Мики.
4. **Лицензия**: ничего платить не нужно, пока выручка проекта ниже 10 млн иен в год; Editor PRO — у риггера.
5. Наушники Рэй (бриф 27, раздел 9) — решить до этапа Рэй, для пробы не нужно.
