# English Club — бриф: интерфейс мессенджера «Телефон»

Версия 1 · 02.11.2026. Что показывать и как это работает; для дизайна макетов и для реализации. Сюжетная часть (кто, когда и что пишет, флирт по стадиям) — [30-messenger-story.md](30-messenger-story.md). Общий стиль приложения — светлая и тёмная темы, ширина телефона 390 px, героини и фоны как в сценах.

## 1. Задача

Встроенный мессенджер, похожий по ощущению на Telegram, но свой по виду: героини пишут игроку между занятиями и в сюжетных эпизодах — текст, голосовые, фото, **исчезающие фото** и **кружочки**. Игрок отвечает по-английски так же, как в сценах: выбирает намерение и собирает фразу. Всё — часть учёбы: чтение, аудирование, письмо, регистр.

## 2. Где живёт

- **Значок телефона** в верхней панели (рядом со стриком и кольцом цели) со счётчиком непрочитанных.
- **Входящее сообщение** во время другого экрана — короткая плашка сверху («Мика: Found it!! …»), нажатие открывает чат. Во время задания плашки нет (не отвлекаем), сообщение ждёт в списке.
- **Сюжетный эпизод в чате** может быть занятием на пути (станция с иконкой 💬 «Переписка»): открывает нужный чат на полный экран, после него — итог занятия, как у обычного.
- **Telegram** (план, раздел 3.11): позже те же сюжетные сообщения дублируются в бота; в приложении — всегда полная версия.

## 3. Экраны

### 3.1. Список чатов

- Карточки: аватар (круглый кроп спрайта героини, для группы — коллаж из трёх), имя, последняя строка, время по календарю истории, счётчик непрочитанных.
- Чаты открываются по сюжету: сначала только **«Room 17»** (группа), личные — с юнита 041; закрытые не показываются.
- Сверху — нет поиска и настроек (их нет в сюжете); снизу — обычное нижнее меню приложения.

### 3.2. Чат

- **Шапка**: аватар, имя, статус («в сети», «печатает…», «была недавно» — по сюжету), кнопка назад.
- **Фон чата**: спокойный узор или размытое место героини (комната 17, общежитие); в тёмной теме — тёмный вариант.
- **Лента**: пузыри героинь слева (цвет героини: Мика — розовый, Рэй — тёмно-лиловый, Айрис — тёплый коричневый, приглушённые), игрок справа (нейтральный акцент приложения); дата-разделители («Вторник»), время мелко в углу пузыря, галочки прочтения у сообщений игрока.
- **Печатает…**: перед каждым сообщением героини — индикатор на 0,6–2 с (зависит от длины); тап по ленте пропускает ожидание.
- **Внизу**: панель ответа (раздел 5) или строка «Мика не в сети» / «Ответ не нужен».

## 4. Типы сообщений

| Тип | Вид | Взаимодействие |
|---|---|---|
| **Текст** | пузырь | английский текст: **тап по слову — перевод** (как в сценах), кнопка «Перевод» под пузырём; в режиме поддержки перевод сразу |
| **Голосовое** | пузырь с кнопкой ▶, волной и длительностью | воспроизведение, скорость 1× / 0,75×; после прослушивания — «Показать текст» (транскрипт с переводом); пока играет — волна подсвечивается |
| **Фото** | превью в пузыре, подпись под ним | тап — на весь экран, жест назад; подпись по-английски с переводом по тапу |
| **Исчезающее фото** | размытое превью со значком 🔥 / ⏱ и подписью «Фото · одноразовое» | **удерживать**, чтобы смотреть; таймер-кольцо 5–10 с (задаётся в контенте); отпустил или время вышло — фото закрывается навсегда, пузырь становится «Фото просмотрено»; в режиме разработчика можно открыть повторно |
| **Кружочек** | круг ~220 px с кольцом прогресса | автозапуск без звука при появлении на экране, тап — со звуком; внутри — **Rive-героиня** (поза, эмоция, губы по голосу) на фоне места; тап по раскрытому — на весь экран; кнопка «Текст» — субтитры с переводом |
| **Реакция** | эмодзи в углу пузыря | долгий тап по сообщению героини — 5–6 эмодзи (❤️ 😂 😮 👍 🙏 🔥); сюжетно иногда реакция и есть ответ |
| **Стёртое** | серый курсив «Сообщение удалено» | для сцены «написала и стёрла» (юнит 100); можно с эффектом «печатает… перестала печатать» |
| **Системное** | по центру мелким шрифтом | «Рэй добавила тебя в чат „Room 17“», «Пропущенный звонок» |

Кружочки и фото героини — только в её стиле и по правилам [30-messenger-story.md](30-messenger-story.md) (раздел 5).

## 5. Ответ игрока

Учебная часть — как сцены с выбором, но в форме мессенджера:

1. Над клавиатурой — **2–3 намерения** чипами по-русски («Пошутить в ответ», «Сказать честно, что приятно», «Пожелать спокойной ночи»).
2. Выбрал — появляется поле ввода (или **плитки слов** в режиме поддержки) с подсказкой «Например: …».
3. «Отправить» → проверка как в сцене: верно — сообщение уходит пузырём, героиня реагирует; непонятно — героиня **переспрашивает** в чате («wait, what do you mean? 😅»), игрок пробует ещё раз (ошибка уходит в повторение, сюжетный выбор засчитывается).
4. **Ответ голосом** — кнопка 🎤 рядом с полем, где сюжет просит голосовое (распознавание, как в заданиях «Голосом»).
5. **Без учебной нагрузки** — реакция эмодзи или кнопка готового ответа («👍»), где это просто жест.
6. Всегда есть вариант «Позже» / «Не сейчас» — без наказания.
7. В режиме разработчика — «Пропустить (засчитать верным)», как в заданиях.

## 6. Поведение и состояния

- История чатов сохраняется; прочитанное помечается; непрочитанное — счётчики в списке и на значке.
- Сообщения по сюжету приходят после события (закончено занятие, открыт юнит) или в эпизоде-занятии; не по реальному времени и не ночью (уведомления — только по настройкам).
- **Одноразовость** исчезающих фото хранится в прогрессе; на странице героини остаётся текстовое воспоминание («Рэй прислала фото выключенного рекордера. Не для архива.»).
- **Уменьшение движения**: без анимации пузырей и кольца, кружочек без дыхания (лицо и губы работают).
- **Офлайн**: всё, что пришло, доступно без сети; голосовые и картинки кешируются, как озвучка сцен.
- **Звуки**: короткий звук входящего, отключается вместе со звуками приложения.

## 7. Визуальный стиль

- Тот же UI-кит приложения (шрифты, радиусы, цвета); пузыри скругление 18 px, хвостик у последнего пузыря серии.
- Светлая и тёмная темы; контраст текста в пузырях не ниже WCAG AA.
- Аватары — круглые кропы спрайтов `neutral` (обновлять при смене наряда в сюжете).
- Анимации: появление пузыря снизу 150 мс, «печатает…» — три точки; кружочек — мягкое появление.
- Ширина 390 px без горизонтальной прокрутки; на широком экране лента не шире 640 px, как остальное приложение.

## 8. Данные (для реализации)

Черновик формата в контенте (`content/chats/*.json`, проверяется схемой):

```json
{
  "id": "rei-081-rain",
  "chat": "rei",
  "unlock": { "unit": "081", "flag": "route_rei" },
  "time": "Friday, 23:10",
  "messages": [
    { "from": "rei", "type": "text", "text": "still up?", "ru": "ещё не спишь?" },
    { "from": "rei", "type": "voice", "text": "Recorded the rain for you.", "ru": "Записала тебе дождь.", "delivery": "[quiet]" },
    { "from": "rei", "type": "photo_once", "image": "rei_081_recorder_off_once", "seconds": 7, "caption": "not for the archive", "ru": "не для архива", "memory": "Рэй прислала фото выключенного рекордера. Не для архива." },
    { "from": "rei", "type": "circle", "expr": "smirk", "place": "room17_evening", "text": "Don't screenshot. I'll know.", "ru": "Не скриншоть. Я узнаю." }
  ],
  "reply": {
    "intents": [
      { "label": "Пошутить в ответ", "answers": ["Too late. It's my wallpaper now.", "I would never. Probably."], "reaction": { "from": "rei", "type": "text", "text": "…", "ru": "…" }, "flag": "rei_081_joked" },
      { "label": "Пожелать спокойной ночи", "answers": ["Good night, Rei.", "Sleep well."], "reaction": { "from": "rei", "type": "text", "text": "night.", "ru": "спокойной." } }
    ],
    "later": true
  }
}
```

Голосовые и кружочки озвучиваются тем же `scripts/generate_audio.py`, фото лежат в `assets/chat/` (WebP), кружочки используют Rive-героинь и фоны `assets/backgrounds/`.

## 10. Приёмка

- [ ] Все типы раздела 4 работают на телефоне и компьютере, в светлой и тёмной теме.
- [ ] Ответ игрока проверяется как в сценах: верно — пузырь и реакция; непонятно — переспрос в чате, ошибка в повторении.
- [ ] Исчезающее фото открывается удержанием, закрывается навсегда, остаётся воспоминанием; в режиме разработчика открывается снова.
- [ ] Кружочек: Rive-героиня с губами по голосу, субтитры, работает при «уменьшении движения» (без дыхания).
- [ ] Перевод по тапу и режим поддержки — как во всём приложении.
- [ ] Юнит 003 (голосовые с расписанием и общий чат) показан в мессенджере.
