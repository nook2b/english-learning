# English Learning with Anime Heroines

Личное приложение для изучения английского: уроки по системе времён, интервальные повторения слов и визуальная новелла с аниме-героинями и романтической линией. Сначала веб и Telegram Mini App, потом мобильное.

**Статус**: проектирование, кода пока нет. Следующий шаг — этап 1 плана разработки (каркас и деплой).
