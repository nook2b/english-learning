# English Learning with Anime Heroines

Приложение для изучения английского: диагностика и личный путь по CEFR, интервальные повторения, мини-игры и визуальная новелла с аниме-героинями и романтической линией. Сначала для меня, но устроено так, чтобы им мог пользоваться и другой человек с другим уровнем и другими проблемами. Сначала веб и Telegram Mini App, потом мобильное.
