# English Club: «Комната 17»

Личное приложение для изучения английского от B1 до C1. Учёба встроена в визуальную новеллу: студент по обмену попадает в радиокомнату 17 и вместе с тремя однокурсницами — Микой, Рэй и Айрис — делает аудиогид, потом эфиры и собственные проекты. Романтическая линия с выбранной героиней проходит через всю кампанию. Сначала веб и Telegram Mini App, потом мобильное.
